PYTHON BOT v0.2.2 — KHỞI ĐỘNG KHÔNG CỬA SỔ ĐEN (WINDOWS)

1. ĐÓNG Python Bot cũ và cửa sổ Terminal đen đang mở.
2. Giải nén vào một thư mục MỚI, ví dụ C:\PythonBot_v022.
3. NHẤP ĐÚP START_PYTHON_BOT.pyw hoặc START_PYTHON_BOT.vbs.
   KHÔNG chạy START_PYTHON_BOT.bat của bản cũ, KHÔNG chạy python_bot.py
   bằng Windows Terminal hay lệnh python.
4. Nếu file .pyw không có tác dụng, cần cài Python 3.11+ từ python.org
   và bật Python Launcher khi cài đặt. Có thể dùng file .vbs.
5. Nếu bot không mở, kiểm tra startup_error.log trong thư mục.

Bản ZIP này cố ý KHÔNG kèm file .bat vì file .bat mở cửa sổ terminal.
Đừng dùng shortcut Desktop cũ trỏ vào .bat: hãy tạo shortcut mới từ .pyw.

Dữ liệu cũ lưu ở %APPDATA%\PythonBot\config.json nên vẫn được giữ.
Bản v0.2.2 giữ nguyên tính năng v0.2.1. Chưa tích hợp Discord.

Cập nhật trong bot cần địa chỉ manifest HTTPS do bạn cấu hình tại Cài đặt.
Chưa có máy chủ phát hành mặc định.
